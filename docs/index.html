Open Source

MEGAzFM Core é um projeto aberto

O núcleo do bot — reprodução de MP3, sistema de estações, fila, volume e os comandos principais — tem código-fonte público. Isso significa:

Código aberto de verdade. O repositório completo do MEGAzFM Core está hospedado no GitHub, disponível para leitura por qualquer pessoa.

Fork livre. Qualquer pessoa pode clonar o projeto e hospedar sua própria instância da rádio, no seu próprio servidor Discord.

Modificação permitida pela licença MIT. O código pode ser estudado, adaptado e redistribuído — inclusive comercialmente — desde que o aviso de copyright original seja mantido (veja o resumo abaixo).

Core ≠ instância oficial. A versão pública representa o conjunto de recursos do Core. A instância que roda oficialmente pode incluir extras que não fazem parte deste repositório — o Core sozinho é completo e funcional por conta própria.

Como o bot funciona

Cada pasta dentro de stations/ é uma estação. Uma estação local contém arquivos MP3; uma estação de transmissão contém um arquivo stream.url apontando para um stream de rádio online.

stations/lofi/ — arquivos .mp3 stations/chill/ — arquivos .mp3 stations/radioweb/stream.url — transmissão ao vivo
SEMPRE ONLINE

Sem músicas, sem crash

Se uma estação estiver vazia, o bot continua conectado ao canal de voz e aguarda. Rode /reload depois de adicionar arquivos.

RECONEXÃO

Voz resiliente

Quedas de conexão são detectadas e reconectadas automaticamente, sem tentativas agressivas ou duplicadas.

LEVE

Baixo consumo

Nenhum MP3 é carregado inteiro na memória. Histórico e fila são limitados de propósito.

Termos de Serviço

Última revisão: setembro de 2026

1. O que é o serviço

MEGAzFM é um bot de rádio para Discord, distribuído como projeto de código aberto (MEGAzFM Core). Servidores que adicionam uma instância do bot fazem isso por sua própria conta, seja usando uma instância hospedada por terceiros, seja hospedando sua própria cópia a partir do código público.

2. Uso aceitável

  • Não use o bot para violar os Termos de Serviço do Discord.
  • Você é responsável pelo conteúdo de áudio (arquivos MP3 ou streams) configurado na sua própria instância.
  • Não redistribua conteúdo protegido por direitos autorais sem autorização.

3. Sem garantias

O software é fornecido "como está", sem garantia de disponibilidade contínua, ausência de bugs ou adequação a um propósito específico.

4. Código aberto

O código do Core está público no GitHub. O uso, modificação e redistribuição do código seguem os termos da licença do projeto (ver seção "Open Source" acima).

Política de Privacidade

Última revisão: setembro de 2026

1. Dados processados

O bot processa apenas o mínimo necessário para funcionar dentro do Discord: IDs de servidor, canal de voz e, quando configurado, canal de texto para avisos. Comandos de administrador (como troca de estação ou volume) não armazenam dados pessoais.

2. O que NÃO é coletado

  • Conteúdo de mensagens do servidor.
  • Dados de áudio dos usuários (o bot não grava nem escuta o canal de voz).
  • Informações pessoais além dos identificadores técnicos do Discord necessários para operar.

3. Armazenamento

Configurações de estação e cooldowns ficam apenas em memória/arquivos locais da instância que executa o bot — não existe um servidor central coletando dados de todas as instâncias.

4. Instâncias de terceiros

Se você usa uma instância hospedada por outra pessoa (um fork), a política de privacidade pode variar de acordo com quem opera aquela instância específica.
